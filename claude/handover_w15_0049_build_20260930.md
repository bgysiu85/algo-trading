## Coding choices you should know about (Amendment 3, PRE-RUN, before any count)
- **C3 pool can lose some of TL-v2's own entries.** The one-live-setup rule (Amendment 2 C1) also applies to the pool's scan, so a non-A+ break can take the slot an A+ break would have used. The report prints how many of TL-v2's entries are in the pool.
- **C3 is matched on entry signals, not filled trades.** The report prints the draws' median filled trades beside TL-v2's.
- **Seen window:** registration sec 3 says "reported only", sec 6 says "never scored". The runner only reads training bars, so it prints the label and confirms 0 seen sessions; it does not score 2025-09-23 onward (same as TL-v1). If you want it scored, that is a separate decision and a separate read of bars this runner cannot reach.
- **Criterion 10:** the 150 in the verdict is fractional-ensemble TRADES; the stop rule's 150 is retest ENTRIES. Entries can clear the stop rule and trades can still come in under 150 (NOT READ).
