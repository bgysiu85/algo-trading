## In plain terms

The tool that shows you one blind chart at a time is built and tested on synthetic bars. It is a matplotlib window on your PC (you asked for matplotlib; one `pip install matplotlib` into your `.venv` is needed). The real-archive build (2,670 candidates, queue, ledger) was already run and matched the registered counts exactly. Now you press T or S, a reason key, Enter, for as long as you like each day; it saves after every decision and resumes where you stopped.

## What was built (`strategy/chartmark_clone/`, 12 files; tests in `tests/strategy/chartmark_clone/`, 38 tests (server.py and its HTTP test were deleted))

| File | Job |
|---|---|
| `spec.py` | every registered constant + interpretations I1–I9 |
| `daily.py` | 18:00-NY trading-day bars, daily EMA9/EMA21/ATR14, F1 daily trend |
| `manifest.py` | re-runs the v1 engine, reconstructs each fill's buy-stop level and **proves it** (engine fill = max(level, open), high ≥ level); reads only `entry_t` of the v1 trades CSV to check timestamps |
| `qorder.py` | queue (24 strata, seeded) + repeat schedule (pure functions) |
| `ledger.py` | G7: SHA-256 of queue, manifest and 1H frame; refuses a rebuild; tool refuses to start on any mismatch |
| `chartdata.py`, `render.py` | the blind chart (matplotlib figure): daily panel, 1H panel, volume, MACD, relative price axis, weekday+hour axis |
| `labels.py` | append-only labels file, undo rows, resume, stop-rule counts |
| `session.py`, `gui.py`, `label.py` | key flow (no window code), the matplotlib window, launcher |
| `build.py` | one-shot builder (manifest, queue, frame cache, ledger, report) |

**Gates (registration §11):** G1 (data cut before 2022 as v1 — uses v1's own `load_training_frame`) · G2 manifest/pool/outcome-column proofs · G3 blinding tests · G4 labels file · G7 queue hash — all tested on synthetic data. **The real-data half of G2 (2,670 fills, per-year counts, timestamps equal to the trades CSV) was run on the real archive this session: it matched the registered 2,670 fills and per-year counts exactly.**

Tests that were checked to be able to fail: leaking one future bar into the chart fails the truncation and last-bar tests; using the whole day for "today so far" fails the daily and render tests.

## Things Ben should know (all in Amendment 1)

- **matplotlib window** (Amendment 1 item 1). Same content as registration §4. Blinding tests run on pixels and on every text in the figure; the truncation test was also repeated on a real candidate from the archive.
- Keys: **T** take / **S** skip, then reason **1–7** (skip) or **A–D** (take, optional), **Enter**. **K** then **1–3** = confidence (digits alone pick the skip reason). **U** undoes the decision you just made, once. **Esc** clears. Reasons 7 and D let you type a few words.
- The chart stops at the bar before the fill, with the order line drawn; price axis is dollars from the order; only weekday and hour are shown.
- One in about eleven presentations after the first 110 is a repeat of an earlier one, unmarked; it measures how consistent you are with yourself.
- The tool tells you when the counts are enough (500 labels and 60 takes, or 1,000) and never stops you.
- **First-run outputs go to `D:\Trading\Claude outputs`, which is git-ignored** (`Claude Outputs/` in `.gitignore`). So the queue's SHA-256 is recorded in the ledger *and* is on the board. The code, tests, registration amendment and this handover are what get committed.
